# Tarea: Mi prompt profesional

Sé uso ***ChatGPT*** para el desarrollo de está actividad.

## Funcionalidad elegida

Cálculo de Notas para colegios y universidades.

## Versión 1: prompt básico

```
Crea un programa en Java para registrar notas.
```

## Versión 2:

```
Actúa como desarrollador Java. Crea un programa en Java para gestionar calificaciones de escolares y universitarios validando que cada nota esté entre 0 y 20 e incluye 4 funcionalidades claves.
```

## Versión 3: prompt final

```
Actúa como desarrollador Java. Crea un programa en Java para gestionar calificaciones de escolares y universitarios validando que cada nota esté entre 0 y 20 e incluye 4 funcionalidades claves, usa una Clase Estudiante con los atributos; nombre, nota, promedio (max 2 decimales) y condición (aprobado o desaprobado). Como restricción, no uses librerias externas. Por último, explica la estructura de la clase y luego presenta el codígo Java.
```

## Componentes del prompt final

| Componente | Texto de mi prompt final |
|------------|--------------------|
| Rol | Desarrollador Java. |
| Instrucción | Crear un programa en Java. |
| Contexto | Gestionar calificaciones de escolares y universitarios. |
| Ejemplo | Usa una Clase Estudiante con los atributos; nombre, nota, promedio (max 2 decimales) y condición (aprobado o desaprobado). |
| Formato | Explica la estructura de la clase y luego presenta el codígo Java. |
| Restricción | No usar librerias externas. |

## Evaluación del resultado

| Criterio | Prompt v1 | Prompt v2 | Prompt v3 |
|----------|-------------|---------|-----------|
| Menciona el objetivo del sistema | Si | Si | Si |
| Tiene restricciones | No | No | Si |
| Tiene de 3 a más funcionalidades | No | Si | Si |
| Lo usarías en un ámbito profesional | No | No | Si |

## Errores que evite

- **No dar contexto del programa:** Así evitamos que la IA genere codigo que no queremos.

- **No indicar restricciones:** Ya que dependiento del país, las notas se manejan de distintas formas.

- **Dar información innecesaria:** ESto puede hacer que la IA demore más tiempo en generar la tarea.
